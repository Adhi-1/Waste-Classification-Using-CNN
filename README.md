# Waste-Classification-Using-CNN
Waste Classification Using CNN is a deep learning project that classifies waste images into six categories: Cardboard, Glass, Metal, Paper, Plastic, and Trash. It uses Python and TensorFlow for image preprocessing, model training, evaluation, visualization, and image upload prediction.

## Project Overview
This project uses a Convolutional Neural Network (CNN) to classify waste images into six categories using deep learning.

## Waste Categories
- Cardboard
- Glass
- Metal
- Paper
- Plastic
- Trash

6. Model evaluation

Includes:
- Training and validation accuracy
- Training and validation loss
- Test accuracy
- Classification report
- Confusion matrix

## Dataset
TrashNet – Six-category waste image dataset.

Dataset source: https://www.kaggle.com/datasets/feyzazkefe/trashnet

## How to Run
1. Download the notebook.
2. Open it using Google Colab.
3. Install the required libraries.
